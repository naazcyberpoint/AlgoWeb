# AlgoWeb - Enterprise Algorithmic Trading Platform Monorepo

Production-grade algorithmic trading platform monorepo.

## Current Paper Trading Dashboard

The frontend app contains the Delta BTC/ETH opposite-pair paper trading dashboard with 15-minute candles, 6-month playback, ₹10,000 simulated capital, 200x simulated leverage, trailing-profit and simulated liquidation logic. Real orders remain disabled.

## Deployment
